# 大棚无人车 STM32 运动控制

我负责项目中 STM32 侧的基础运动控制。目前已经完成串口收发、双路电机控制、编码器计数和轮速反馈，并完成两轮前进、主动停车和停止续发指令后自动停车的短时架空测试。右轮方向问题已经在程序中修正，2026 年 10 月 24 日的修正版固件已烧录并通过下载校验。

当前控制方式是**有符号占空比控制**：电脑发送两路占空比，STM32 控制电机并返回计数、RPM 和运行状态。目标 RPM、轮速闭环、车体速度接口和 ROS 节点还没有实现；现有结果也不包含落地直线、带载或连续运行测试。

其中最容易混淆的两点是：**本车 A 是右轮，B 是左轮；D 指令里的数值是占空比，不是目标 RPM。** 相同占空比不保证相同轮速，也不能据此判断小车落地能走直线。

## 工程结构

```text
Core/Inc/chassis_control.h   命令解析 斜坡与状态机
Core/Inc/chassis_port.h      硬件适配 串口 软件 PWM 与运行入口
Core/Inc/chassis_encoder.h   编码器计数算法
Core/Inc/chassis_speed.h     RPM 换算及手动标定参数
Core/Src/main.c             初始化与主循环
Drivers/                   STM32 HAL 与 CMSIS
tools/motion_link.py        电脑端串口示例
tools/test_motion_link.py   协议工具测试
docs/                      当前说明和测试记录
artifacts/                 已烧录固件及对应版本信息
```

工程使用 STM32CubeIDE，目标为 STM32F103 系列；当前构建配置为 STM32F103xB，链接脚本为 `STM32F103C8TX_FLASH.ld`。最近一次编译使用 STM32CubeIDE 2.2.0 和 GNU STM32 14.3.rel1，未在另一台电脑上验证完整构建流程。IDE 配置中的工具链或链接脚本路径可能需要随环境调整。

串口、软件 PWM 等初始化包含在 USER CODE 和寄存器配置中，`.ioc` 不能单独代表当前全部逻辑。重新生成 CubeMX 代码时，必须保留并核对这些初始化。

## 电脑端示例

以下命令在本工程根目录执行。安装依赖后，不带端口运行只打印协议示例，不访问硬件。

```powershell
python -m pip install -r requirements.txt
python tools/motion_link.py
```

实际运动示例见[接线和运行方法](docs/接线与运行.md)。本版只做过短时架空测试，电机与驱动板的电流匹配、保护和带载条件仍待确认。烧录、复位或暂停 CPU 前，先物理拔下两个白色电机插头。

2026 年 10 月 24 日已烧录版本及对应 map 保存在 [artifacts/stm32_motion_20261024](artifacts/stm32_motion_20261024/README.md)，测试原始记录位于 `docs/evidence/20261024/`。固件与代码后续修改后的结果会另行记录。
