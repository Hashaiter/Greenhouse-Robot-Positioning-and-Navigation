本版完成了短时架空前进、主动 STOP 和停止续发运动命令后的自动超时停车测试。当前是占空比控制，还没有目标轮速闭环、ROS 节点或落地带载验证。

构建环境：STM32CubeIDE 2.2.0，GNU STM32 14.3.rel1。text 18476、data 92、bss 2748 字节。烧录、复位或暂停 CPU 前先物理拔下两个白色电机插头，具体接线和供电见[运行说明](../../docs/接线与运行.md)。
